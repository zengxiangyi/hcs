- **通用结论（今后遇同类问题直接查这里）**：前端接口地址两个来源——dev = `vite.config.ts` 的 proxy（重启 dev 即可）；生产 = `.env.production` 的 `VITE_API_BASE_URL`（必须重新 `npm run build:war`）。值只能填后端 origin 根，禁止带 `/api`。
