## 修复「改了 vite proxy target，发布后接口仍是 127.0.0.1:8080」
- 根因：`vite.config.ts` 的 `server.proxy` **只对 `npm run dev` 生效，不参与打包**。生产接口地址来自 `frontend/.env.production` 的 `VITE_API_BASE_URL`（`src/api/http.ts:17` 用它做 axios `baseURL`）。
- 改动：`frontend/.env.production` → `VITE_API_BASE_URL=http://10.21.46.191:8080`；同步修正 `vite.config.ts`、`src/api/http.ts`、`CODEBUDDY.md` 中过时的 127.0.0.1 说明，并在注释里写明「dev 改 proxy / 生产改 .env.production 且必须重新 build:war」。
- **通用结论（今后遇同类问题直接查这里）**：前端接口地址两个来源——dev = `vite.config.ts` 的 proxy（重启 dev 即可）；生产 = `.env.production` 的 `VITE_API_BASE_URL`（必须重新 `npm run build:war`）。值只能填后端 origin 根，禁止带 `/api`。
- 前后端同 Tomcat 同源时更推荐填 `/`（自动跟随浏览器 origin，换 IP/域名免重新打包）；跨机访问填 IP 也可行，后端 `CorsConfig` 已放开 origin（`*`）+ 关闭 credentials。
- 本次仅改配置与注释，**未执行 `npm run build:war`**（命令被跳过），新地址需重新打包才生效；上线用 `.\deploy-test.ps1 -Part Front`。
