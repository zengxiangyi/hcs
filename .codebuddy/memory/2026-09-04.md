## ConstValue 链路代码评审（2026-09-04）

- 评审范围：ConstValueController / Service / Repository / Mapper / Mapper XML / Entity / DTO。
- 结论：分层清晰，整体良好。发现主要问题：
  1. `POST /constValue/save` 不符合 REST，建议改 `POST /constValue`；
  2. 错误处理不一致：getById 返回 null（200）、update 找不到抛 NPE（500）、delete 抛 404，建议统一 ResourceNotFoundException；
  3. code 唯一性为 check-then-act，需 DB 唯一索引兜底；
  4. pageSize 无上限、分页参数手工校验，建议 @Valid + @Max；
  5. Mapper XML 表名 constvalue 全小写符合项目约定。
- 用户确认后已完成修改（2026-09-04）：
  1. `POST /constValue/save` → `POST /constValue`（后端 Controller + 前端 `src/api/constValue.ts` 已同步）；
  2. `getById`/`update` 找不到统一抛 `ResourceNotFoundException`（404），`getByCode` 保留查无返回 null 语义；
  3. `ConstValueQuery.page/pageSize` 改 int + `@Min(1)`，pageSize 上限 200，Controller 改用 `@Valid`；
  4. Entity `code` 补 `@NotBlank`；update 加显式拷贝注释。
- 遗留：code 唯一索引需 DBA 执行 SQL（`ALTER TABLE constvalue ADD UNIQUE KEY uk_constvalue_code (code)`）；code 冲突当前走 IllegalArgumentException→400，可后续映射 409。
