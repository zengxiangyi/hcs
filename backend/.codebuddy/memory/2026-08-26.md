## Bug：获取登录用户 ClassCastException

- 根因：`JwtAuthenticationFilter` 设的 principal 是 **String 用户名**，`(User) getPrincipal()` 强转崩溃。
- 修复：抽公共方法 `tool/UserInfo.currentUsername()`，内部 `instanceof User` / `instanceof String` 分情况处理；`BluePrintController.save()` 改用它。
- 教训已入 MEMORY.md「获取登录用户」。

## Bug：保存时 createTime 为空（必现）

- 根因：`BluePrintService.save()` 里有一行 `setCreateTime(null)`（注释写"由服务端填充"但无填充逻辑），把 Controller 刚设的值清空。**已删除该行**，改由 Controller 用 `DateTimeTool.currentTime()` 填充。
- `blueprint` 表时间列名确认为 **`createtime`**（全小写无下划线），实体 `@Column` 正确。
- `BluePrintMapper.xml` 的 `Base_Column_List` 与 4 处 `ORDER BY` 原误用 `create_time`（列不存在），统一改为 `createtime`。
- 教训：BluePrint 系列表列名全小写无下划线（createtime / firstlevel / materialname），Info 表用 snake_case（create_time）——两表约定不同，改列名前必查库或问用户。
