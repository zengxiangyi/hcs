## SecurityConfig + CorsConfig 代码评审（只出报告，未改代码）

评审范围 `config/SecurityConfig.java`、`config/CorsConfig.java`（连带读了 `JwtAuthenticationFilter`、`ApiResponse`、`application.properties`）。核心结论：

- **P0-1（新发现，功能性缺陷）**：`CorsConfig` 暴露的是 `CorsFilter` bean（无 `@Order` → LOWEST_PRECEDENCE），而 `HttpSecurity` **未调用 `.cors(...)`**，`springSecurityFilterChain` 以 -100 先执行 → **浏览器 OPTIONS 预检被 `AuthorizationFilter` 拦成 401**。普通跨域请求不受影响（CorsFilter 在响应阶段补头），只有带自定义头（本项目即 `Authorization`）的跨域才必现。修法：CorsConfig 改为暴露 `CorsConfigurationSource` bean，SecurityConfig 加 `.cors(Customizer.withDefaults())`。
- **P0-2 历史 I2 未修**：`JwtAuthenticationFilter` 仍带 `@Component`，与 `addFilterBefore` 双重注册；`OncePerRequestFilter` 的 alreadyFiltered 标记在内层执行完即被清除 → 每个请求 JWT 验签真的跑两遍。应去掉 `@Component`，改在 SecurityConfig 里 `@Bean`。
- **P0-3 历史 S2 未修 + 新增双真源**：`startsWith(prefix)` 会误放行 `/authXxx`；且放行路径写了两遍（`SecurityConfig` 硬编码 `/auth/**` vs 过滤器读 `jwt.auth-path`），改一侧即出事。建议 SecurityConfig 注入同一 `${jwt.auth-path:/auth/**}` 并换 `AntPathRequestMatcher`。
- **I1 已确认修复**：`requestMatchers("/auth/**")` 与 `request.getServletPath()` 均匹配去掉 context-path 后的路径，与 `/api` 一致。
- **P1**：无效 token 走 `sendError` → Boot 默认 error body，与 `ApiResponse` 401 格式不统一（应改抛 `BadCredentialsException`）；未配 `AccessDeniedHandler`；401 里每次 `new ObjectMapper()`（应注入）；
- **文档漂移（重要）**：`CODEBUDDY.md` / `MEMORY.md` 写 CORS 走 `app.cors.*` 前缀 + `application.properties` 生产示例 —— 全仓库 `app.cors` **0 命中**，prod 配置文件**不存在**，实际是硬编码常量。**后续需更正这两处文档**。

## P0-2 修复：JwtAuthenticationFilter 双重注册（已完成）

- **根因**：`@Component` 让 Boot 把该 Filter 自动注册进 Servlet 容器链（LOWEST_PRECEDENCE），同时 `SecurityConfig:56` 的 `addFilterBefore` 又把它加进 Security 链（order -100）。同一单例在同请求中出现两次；`OncePerRequestFilter` 的 alreadyFiltered 属性在内层 finally 中被清除，外层看不到标记 → 每个请求真跑两遍验签。
- **关键认知**：`@Component` → `@Bean` **不能解决**，两者都是 Filter bean，都会被 Boot 自动注册。必须额外声明 `FilterRegistrationBean` 并 `setEnabled(false)`，Boot 的 `ServletContextInitializerBeans` 才会把它标记为已处理、不再追加默认注册。
- **改动**：
  - `JwtAuthenticationFilter`：去掉 `@Component` 及其 import，类 Javadoc 写明"故意不组件扫描"及原因；顺带修正过期的 `/info/auth/**` 为 `/auth/**`。
  - `SecurityConfig`：删除构造器注入（保留会与同类 `@Bean` 形成循环依赖），改为 `@Bean jwtAuthenticationFilter(JwtUtil)` + `@Bean jwtAuthenticationFilterRegistration(...).setEnabled(false)`；`securityFilterChain` 改为方法参数注入 Filter。
- 验证：`mvnw.cmd -o -q compile` exit 0。**未做运行时启动验证**（无测试类、启动需本地 MySQL）。
