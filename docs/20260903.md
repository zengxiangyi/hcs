## 四、沉淀的约定与教训（团队知识）

1. **部署**：外置 Tomcat 下 `server.port` 与 `server.servlet.context-path` 均被忽略，context-path 由 war 文件名决定 —— 后端文件名必须是 `api.war`，前端是 `hcs.war`。
2. **`.env.production` 的 `VITE_API_BASE_URL` 只填 origin，绝不带 `/api`**（`src/api/*.ts` 写的是完整路径），否则拼成 `/api/api`。
3. **war 打包必须写目录条目**（`Compress-Archive` 不写），否则 Tomcat 11 解压报 FileNotFoundException。
4. **vue-router 的 `name` 必须唯一**，重名会静默破坏 name 相关判定（守卫白名单失效），且不报错。
5. **`unplugin-vue-components` 只自动导入模板中的组件**，脚本作用域必须显式 import；`GlobalComponents` 不是脚本里的值。`components.d.ts` 是生成物，改它没用，改/删源文件才有效。
6. **`el-table` 插槽 `{ row }` 是 `DefaultRow`**，传给业务类型函数要写 `row as XxxRow`。
7. **Element Plus 表格没有 `hidden` prop**，隐藏列只能用 `v-if`。
8. **`el-checkbox` 数组型 v-model 需 script 侧 `Ref` 别名断言**，`v-model` 不能接 `as`。
9. **Vue SFC 跨组件复用必须抽 `.ts`**；动态组件的表单数据由父级持有，子组件用 `defineModel` 拿同一引用，否则切步骤丢数据。
10. **数量类字段换 `el-input-number` 要同时处理四点**：类型（`string` → `number | null`）、DTO 组装、重置、接口回填。
11. **删除 git 已跟踪文件前必须当场重读内容**，本仓库存在并发编辑（用户 / 多 agent）。
12. **JPA 派生删除天然是"先 select 再按 id 删"**；`@Component` → `@Bean` 不能解决 Filter 双重注册，必须 `FilterRegistrationBean.setEnabled(false)`。
13. 仓库约定：删除必须先查实体再按主键删（用户既有代码风格）；DDL 由 DBA 执行，`ddl-auto=none`。
