## 修复：登录失败 401 导致前端无法跳转登录页
- 根因：登录失败曾返回 HTTP 401，被前端 `http.ts` 拦截器当作「token 失效」→ 清 token + `window.location.href='/'` 整页跳转，覆盖了 Login 逻辑；且密码格式不一致导致恒 401。
- 修复（前端侧）：后端登录失败改返回 400（业务错误语义）；`Login.vue` catch 弹窗文案改用 `err?.message || '登录失败'`，移除多余 `router.push('/login')`。
- 契约：HTTP 401 = token 失效（清 token + 跳 `/`）；业务失败用 400 不用 401。
