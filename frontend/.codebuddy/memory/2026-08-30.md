## 改造：instance.vue 改为按 URL 参数 workflow 的纯查看页
- 需求：删除页面所有查询条件（当前节点区 + 历史记录区两个查询表单、分页、搜索/重置逻辑），页面改为「流程实例查看」，通过 URL 参数 `workflow` 展示该实例的当前节点信息和历史操作记录。
- 实现：`useRoute()` 读取 `route.query.workflow`（computed，兼容数组），`watch(workflow)` + `onMounted(loadAll)` 触发；无参数时显示 `el-empty` 提示「缺少流程编号参数（workflow）」。
