# 2026-08-30

## src/components/workflow/draw.vue 修复（ts-plugin：nodeForm 可能为未定义）
- `nodeForm` 由 `ref<FlowNode>()` 改为 `ref<FlowNode>(createNode())`，消除模板 `v-model="nodeForm.xxx"` 的“可能为未定义”报错。
- `openNodeEdit/openEdgeEdit` 增加行下标存在性校验；`submitNode/submitEdge` 增加下标范围校验，越界时按新增处理，避免数组空洞。
- `submitNode/submitEdge` 提交后调用 `renderCanvas()`，编辑后画布即时刷新（原先改坐标不重绘）。
- 首屏加载由 `watch(flowGraph, load, { immediate: true })` 改为 `onMounted(load)` + `watch(flowGraph, load)`，确保 `#flow-canvas` 已挂载。
- 新增 `parseAxisString()` 包裹 `JSON.parse(edge.axis)`，脏数据不再抛错中断整图渲染。
- 连线箭头绘制条件由 `points.length > 0` 改为 `>= 2`，避免 `points[-1]` 越界。
- `nodeLabel` 改用 computed `nodeMapByCode`（Map）替代逐行 `find`，表格渲染 O(n²) → O(n)。
- 模板“操作人分类”列原误用 `shapeOptions/row.shape`，改为 `operatorOptions/row.operator`。

## 项目约定 / 注意
- 后端 `FlowNode/FlowEdge.id` 类型为 `number`；`X/Y/W/H` 为字符串，绘制时用 `parseNum/parsePoint` 兜底。
- `shapeOptions` 值为 `RECT/CIRCLE`，`categoryOptions` 为 `S/T/D/E`，`edgeCategoryOptions` 为 `A/B/C`；`createNode/createEdge` 默认值为 `task/rect`、`normal`，与下拉选项不一致（已知，未改，避免与后端域值冲突）。
- 类型检查命令：`npx vue-tsc -b`（PowerShell 下用 `Set-Location`，不要用 `cd /d`）。
