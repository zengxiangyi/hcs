## 实现 用户-角色-权限（RBAC）管理系统（hcs/sys 模块）
- 场景：前端 mock 演示，控制页面查看权限（菜单 + 路由守卫）与按钮操作权限。
- 新增文件：
  - `../../src/components/sys/mock.ts`：内存数据源（users/roles/rights + userRoleMap/roleRightMap 关联表），及 getRightCodesByUser 等计算函数。
  - `../../src/components/sys/permission.ts`：权限中心，setCurrentUser(userId) 写入当前用户权限 code 集合到 localStorage；hasRight(code) 判断；restoreCurrentUserRights() 刷新恢复。
  - `user.vue` / `role.vue` / `right.vue`：三个 CRUD 页（按钮权限用 hasRight 控制禁用）。
  - `roleUser.vue`：选角色→勾选用户（反向维护 userRoleMap）。
  - `roleRright.vue`：选角色→按模块分组勾选权限（反向维护 roleRightMap）。
- 打通链路：
  - `src/router/index.ts`：注册 5 个 /web/hcs/sys/* 路由，meta.right 标记页面权限；beforeEach 守卫校验 token + page:* 权限（无权限回跳 Web 带 noAuth）。
  - `src/components/MenuBar.vue`：菜单递归 filterMenu 按 right 字段过滤；菜单项需带 right 字段才受控。
  - `src/config/menu.json`：系统管理分组 5 个子项 path 改为 /web/hcs/sys/* 并加 right 字段。
  - `src/components/Login.vue`：登录成功后按 username 匹配 mock users 调 setCurrentUser 写入权限。
  - `src/components/Web.vue`：监听 route.query.noAuth 提示无权限。
- 注意：mock 数据刷新即重置；真实接入后端时把 mock.ts 的导出替换为 API 调用，并让登录接口返回权限集合。
