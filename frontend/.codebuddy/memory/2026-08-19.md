# 2026-08-19

## 白屏修复（重要）
- 现象：`npm run dev` 后整页空白，dev server 与各模块均 200。
- 根因：`main.ts` 的 `import zhCn from 'element-plus/es/locale/lang/zh-cn'`，新版 element-plus(2.11.5+) 该目录下只有 `.mjs`，裸说明符解析失败 → main.ts 加载中断 → `app.mount` 不执行 → `#app` 永远空。
- 修复：改为 `element-plus/es/locale/lang/zh-cn.mjs`。经验：升级 Element Plus 后需核对 locale 子路径。
