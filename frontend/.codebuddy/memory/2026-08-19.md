## 白屏问题诊断与修复
- 现象：`npm run dev` 后 http://localhost:5173/ 整页空白，dev server 正常监听、所有源码模块编译均返回 200。
- 根因：`src/main.ts` 第 6 行 `import zhCn from 'element-plus/es/locale/lang/zh-cn'` 路径失效。新版 `element-plus@2.11.5` 的 `es/locale/lang/` 下只有 `.mjs`（无 `.js`），浏览器 ESM 加载该裸说明符时解析失败，导致整个 `main.ts` 模块加载中断、`app.mount('#app')` 永不执行 → #app 永远空白。
- 修复：改为 `element-plus/es/locale/lang/zh-cn.mjs`（官方推荐路径）。
- 注意：诊断时在 main.ts 临时加过全局错误兜底并临时安装 jsdom 用于 SSR 复现，均已移除；jsdom 已从 package.json devDependencies 删除（node_modules 残留不影响运行）。
- 经验：Element Plus 升级后 locale 路径由 `.js` 变 `.mjs`，升级依赖后需核对静态资源/子模块路径。
